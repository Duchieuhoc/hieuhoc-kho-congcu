# Kho công cụ Hiếu Học (vẽ hình + template docx)

Chỉ chứa CÔNG CỤ (code + template). KHÔNG chứa nội dung bài, đáp án, hay nguồn SGK.

Bung kho ở sandbox OB / AI Soạn (đầu mỗi thread):
1. Tải kho về (git clone hoặc tải zip)
2. `npm install`  (tự dựng lại node_modules từ package.json)
3. Dùng: python render hình (tikz→pdflatex→png) · node build docx qua hieuhoc_template.js

Dấu phiên bản: xem `00_KHO_VERSION.txt`.
